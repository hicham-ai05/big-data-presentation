# Le Rôle du Big Data - Interactive Presentation

A professional, interactive web-based presentation about the role of Big Data in modern life.

## 🎯 Features

- **9 Complete Slides** covering Big Data fundamentals and applications
- **Animated Particle Background** - Dynamic neural network visualization
- **Premium Animations** - Smooth transitions and micro-interactions
- **Interactive Navigation** - Arrow keys, buttons, and progress tracking
- **Speaker Notes** - Toggleable presentation script
- **Presentation Timer** - Track your presentation duration
- **Responsive Design** - Works on all screen sizes

## 🚀 Quick Start

1. Clone this repository:
```bash
git clone <your-repo-url>
cd projet-big-data
```

2. Open `index.html` in your browser:
```bash
# On Windows
start index.html

# On macOS
open index.html

# On Linux
xdg-open index.html
```

## 📋 Presentation Content

1. **Title Slide** - Introduction with presenter and supervisor information
2. **5V Definition** - Volume, Vitesse, Variété, Véracité, Valeur
3. **Individual Impact** - How Big Data affects daily life
4. **Society Impact** - Big Data's role in communities and governance
5. **Real Project Example** - Weather streaming pipeline (Python + Kafka + Streamlit)
6. **Big Data Power** - Why simple data becomes powerful
7. **Future Trends** - AI, Edge Computing, Smart Cities, IoT, Data Ethics
8. **Conclusion** - Philosophical quote about Big Data
9. **Thank You** - Contact information

## 🎮 Controls

- **Arrow Keys** (← →) - Navigate between slides
- **On-screen Buttons** - Click to navigate
- **Notes Button** - Toggle speaker notes
- **F11** - Fullscreen mode (recommended for presenting)
