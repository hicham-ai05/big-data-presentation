Architecture de Bout en Bout

Motif "Lambda" (Big Data)

Notre conception repose sur une séparation claire des responsabilités :

  • 1. Ingestion : Scripts Python collectant la donnée brute.
  • 2. Broker (Courtier) : Distribution asynchrone haut débit (Kafka/Azure).
  • 3. Destination (Sink) : Stockage structuré pour l'analyse décisionnelle.

Le Producteur Python

Ingestion Continue des Données

Un script robuste interrogeant de manière asynchrone l'API OpenWeatherMap toutes les 10 secondes.

Processus de Sérialisation :
Les données (Température, Humidité, Vitesse du Vent) sont extraites, formatées en JSON, et poussées vers le topic Kafka de manière atomique.
producer.py - VS Code 
import json
import time
import requests
from kafka import KafkaProducer

def fetch_weather(city="Paris"):
    url = f"http://api.openweathermap.org/data/2.5/weather?q={city}&appid=API_KEY"
    res = requests.get(url).json()
    return {
        "city": city,
        "temperature": res["main"]["temp"],
        "humidity": res["main"]["humidity"],
        "wind_speed": res["wind"]["speed"]
    }

producer = KafkaProducer(
    bootstrap_servers=['localhost:9092'],
    value_serializer=lambda v: json.dumps(v).encode('utf-8')
)

while True:
    data = fetch_weather()
    producer.send('weather_topic', data)
    print(f"Sent: {data}")
    time.sleep(10)

Intégration Kafka & Azure

Apache Kafka

Hébergé localement ou sur des machines virtuelles dédiées. Offre un débit ultra-élevé et un contrôle total sur l'infrastructure et la configuration des partitions.

Azure Event Hubs

Service cloud entièrement géré (PaaS). Permet une scalabilité automatique (cloud scale) sans gestion de serveurs, avec une intégration native à l'écosystème Azure.

Stockage PostgreSQL

Persistance Relationnelle

Les flux de données bruts sont consommés, validés, et structurés dans des tables relationnelles.

  • Intégrité transactionnelle (ACID)
  • Indexation temporelle pour requêtes BI rapides
  • Historisation complète des événements météo
